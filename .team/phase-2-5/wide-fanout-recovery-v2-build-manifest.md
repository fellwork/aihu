## Phase B — Restricted leaf-computed inline settle + `shallowClearFired` removal

**Commit:** `2790610` — `perf(signals): Phase B — restricted leaf-computed inline settle`

**Files:**

- `packages/signals/src/signal.ts` — modified
  - Added `/** @internal */ export const HAS_COMPUTED_DEPS = 0x80` constant with doc-comment per spec §3 correctness invariant.
  - Removed `export let shallowClearFired = false` and its doc-comment (no longer needed).
  - Removed `shallowClearFired = true` assignment from `shallowClear`.
  - Removed `shallowClearFired = false` reset from `clearVisited`.
  - Replaced `markOne`'s tail with the restricted leaf branch per spec §5 pseudocode:
    ```
    const inner = sub.subs as Set<Subscriber>
    if (inner.size === 1 && !(sub.flags & HAS_COMPUTED_DEPS)) {
      let only: Subscriber | undefined
      for (const s of inner) { only = s; break }
      if (only !== undefined && only.flags & EFFECT) {
        markOne(only)
        sub.recomputeIfNeeded?.()
        return
      }
    }
    propagateMark(inner)
    ```
  - Removed the dead `inner !== undefined && inner.size > 0` guard (the `EFFECT` branch returns earlier; computeds always have `subs` defined). Type narrowed via `as Set<Subscriber>`.

- `packages/signals/src/computed.ts` — modified
  - Imports: added `HAS_COMPUTED_DEPS`; removed `shallowClearFired`.
  - `read` closure: when the observer is a computed (`observer.subs !== undefined`) reading this computed, OR `HAS_COMPUTED_DEPS` into `observer.flags`. One-way set — once true, the leaf path skips this observer forever (sufficient-not-necessary correctness per spec §3).
  - `recomputeIfNeeded`: removed `if (!shallowClearFired) return` guard. Re-assert MARKED loop is now unconditional — a no-op OR over already-set bits in the common case. Saved 14 B funded the leaf branch addition.

**Why:** spec §5 pseudocode + §3 correctness invariant. The leaf branch
collapses Phase 2 dispatch for confirmed source-only-deps computeds with
exactly one effect sub; HAS_COMPUTED_DEPS conservatively excludes the
correctness-fragile graphs that broke Avenue B (NOTIFIED-dedup `c`,
cellx 4×4 L4 nodes, diamond L2a — each reads ≥ 2 computed deps so the
flag is set on first body run, and the leaf path skips them forever).

  - `computed.test.ts:362+` — NOTIFIED-dedup graph (validates restricted-leaf correctness) ✓

Decision: ship as designed, no §6 fallback (1) inline-edits, no fallback (2) cap renegotiation, no fallback (3) restricted-leaf-only downgrade. Bundle delta vs Phase A: same byte count (1015 B → 1015 B); the `HAS_COMPUTED_DEPS` + leaf branch additions (~+15 B) were funded by the `shallowClearFired` removal (~−14 B) plus dead-guard removals (~−4 B), net within gzip rounding.
