Durable, agent-driven room

The <task-list> below is a real aihu Web Component, but its state lives in a Cloudflare Durable Object — not this tab. Open this page in a second tab (or on your phone), then drive the room as an agent would; every connected viewer updates live, and the state survives a refresh.

Drive it as an agent (authorized + rate-limited, executed in the Durable Object): 

curl -XPOST /agent/call -H 'content-type: application/json' \
  -d '{"tool":"task-list/setVariant","params":["danger"],"userId":"u1","jwt":"tasks:write"}'
