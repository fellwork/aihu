Agent-driven, durable component

The <task-list> below is a real aihu custom element with durable signal state. An external agent reads its @agent metadata and drives this exact visible instance over a WebSocket — gated server-side, executed here in the browser. Drive it with:
curl -XPOST localhost:5208/agent/call -H 'content-type: application/json' -d '{"tool":"task-list/addTask","params":["Write the launch post"]}'
