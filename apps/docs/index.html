What is aihu?

aihu is a complete meta-framework for the agentic web. You write .aihu Single-File Components (SFCs) — block-structured with @state, @template, @style, and @agent blocks — and a Rust compiler emits standards-compliant Web Components and machine-readable agent manifests. The runtime is sub-2 kB. Every component is discoverable by AI agents and callable as an MCP tool out of the box.

Key features

  • Agentic-first — every component is agent-callable by construction via the @agent block.
  • Sub-2 kB runtime — signals, computeds, effects, and DOM diffing in under 2 kB gzipped.
  • Vanilla custom elements — no framework lock-in at the consumer boundary.
  • Zero dependencies — no non-@aihu/* runtime dependencies across all packages.
  • MCP + agent-first — @aihu/agent and @aihu/agent-readiness are first-class packages.
