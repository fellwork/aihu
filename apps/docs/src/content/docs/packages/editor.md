# @aihu/editor

Hand-rolled, dependency-free, GX-governed rich-text editor — JSON document model, invertible transactions, markdown (web-v1 dialect) round-trip, a contenteditable view with IME-safe read-back, and an agent read/suggest/write surface.

> **Status: stub.** A full guide is coming in the docs-content refresh. Until then, the package [README](https://github.com/fellwork/aihu/tree/main/packages/editor) is the authoritative reference.

```bash
bun add @aihu/editor
# or
npm install @aihu/editor
```
