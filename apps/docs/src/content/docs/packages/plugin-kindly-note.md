# @aihu-plugin/kindly-note

Runtime syntax highlighting + markdown rendering for aihu — `<aihu-code>` / `<aihu-markdown>` custom elements plus signal-aware `highlight()` / `renderMarkdown()` helpers, powered by the published `@kindly-note/*` packages with lazy loading.

> **Status: stub.** A full guide is coming in the docs-content refresh. Until then, the package [README](https://github.com/fellwork/aihu/tree/main/packages/plugin-kindly-note) is the authoritative reference.

## Install

```bash
bun add @aihu-plugin/kindly-note
# or
npm install @aihu-plugin/kindly-note
```
