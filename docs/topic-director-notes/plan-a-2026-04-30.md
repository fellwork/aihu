## 3. Scope signal

**Recommend: telemetry-fix first, then Phase 4 → Phase 5 sequential.** The telemetry fix is ~5 minutes and recovers signals headroom that Phase 4/5 do not consume but that future phases (runtime+agent will eventually integrate with signals via consumers, not bundle) and the bench-spike axis depend on. Landing it first prevents the signals-headroom investigation from being polluted by other in-flight work. Phase 4 → Phase 5 sequential rather than parallel because: (a) the wall-clock cost is small (Phase 5 is two functions); (b) the cellx+arbor parallel pattern from Phase 3 (Learning #19) required disjoint files — runtime and agent are disjoint, so parallel is *possible*, but the orchestration overhead of two concurrent Builder threads exceeds the wall-clock savings on a 3-file package. Reserve parallel-instance pattern for genuinely large concurrent workstreams.
