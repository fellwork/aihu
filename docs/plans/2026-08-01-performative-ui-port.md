# Porting the performativeUI catalog into aihu — roadmap + Slice 1

**Date:** 2026-08-01
**Status:** Design. Slice 0/1 in progress.
**Source:** `github.com/vorpus/performativeUI` — MIT per its `package.json` `license` field; no
`LICENSE` file in the tree.
**Provenance rule (binding on every slice):** *transcribe in spirit, never vendor.* No `pui-`
prefixed class name, no source CSS text, no React component body is copied — every ported
component is written as aihu-native code from a behavioral description, matching the convention
already used in `recipes/badge.css` ("transcribed in spirit (not vendored)"). Per explicit user
direction, this ships as close design/behavior/style inspiration reimplemented in aihu-native code.

**Theming decision:** every new component in this port is authored with `shadow: 'light'` from the
start (not the true-shadow-DOM `badge.aihu` shape) — see the parent execution plan for the full
reasoning. `fellwork-web` and `aihu` are both headed toward `shadow: 'light'` as the repo-wide
default by the end of this initiative (the light-DOM leaf flip), and true shadow-DOM components'
`--color-*` tokens are baked into a single compile-time `:host {}` literal with no dark-mode
counterpart — a real gap, out of scope for this port, that `shadow: 'light'` sidesteps entirely.

## 1. Escalations — ruled

> **E-P1 — gradient.** One token, `--gradient-brand`, holding a full `linear-gradient(...)` value.
> Not three separate stop tokens.

> **E-P2 — `--font-serif`.** Added as a bug fix (the utility already referenced it). Default value
> is a system-serif stack, not a specific webfont name.

> **E-P3 — glass surface.** No new tokens — derived per-recipe via `color-mix()` + a literal
> `backdrop-filter: blur(12px)`.

Net: exactly 3 new tokens (`--gradient-brand`, `--font-serif`, `--ease-brand`).

## 3. Slice 1 — implementation notes

See the execution plan for the full token-mapping table and per-component spec — summarized here:

- Token layer: `--gradient-brand`, `--font-serif`, `--ease-brand` added to `AIHU_BRAND_TOKENS`
  (`theme.rs`), both packs (`packs.ts`), the non-color-scalar list in `style-pack.test.ts`,
  regenerated pack CSS, 5-platform bump.
- Two lossy source-role mappings resolved without new tokens: "raised surface" → `--color-surface`
  (documented divergence); "idle/offline" → `--color-neutral` (non-lossy, reuses the daisyUI port's
  E2 token).
- 3 components, all `shadow: 'light'`, all Phase-1-light: `status-dot`, `gradient-text`,
  `eyebrow-pill` (the last exercises `registryDependencies` on the first, currently unused by any
  shipped component).
- No recipe-channel files touched — component CSS lives in each component's own `@style` block.
